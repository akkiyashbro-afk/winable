PREMIUM MOTION PASS — ADD LIFE WITHOUT OVER-ANIMATING

The current WinsAble website design is already established and should NOT be redesigned.

I want to add subtle, premium motion so the website feels alive and professionally crafted, while preserving the existing editorial/minimal aesthetic.

Think:
high-end creative studio / editorial portfolio / premium digital agency.

DO NOT make it flashy.
DO NOT add generic floating particles.
DO NOT add excessive glowing circles.
DO NOT turn the website into a gaming-style animated website.

The animation should be something users FEEL rather than immediately notice.

==================================================
1. PRESERVE EVERYTHING
==================================================

Do NOT remove or rewrite existing:

- layout
- typography
- sections
- content
- navbar
- mobile navbar
- Contact placement
- footer
- Recovery Wall
- Case Form
- platform rows
- existing scroll reveals
- hover effects
- smooth scrolling
- clipboard functionality
- LinkedIn link
- X link
- existing responsive fixes

This is ONLY a motion/visual polish pass.

==================================================
2. AMBIENT BACKGROUND MOTION
==================================================

Add a very subtle animated ambient background layer.

Use the existing black/dark WinsAble visual language.

Create extremely soft, low-opacity purple/indigo atmospheric gradients that slowly move behind the content.

The movement should be:

VERY SLOW
SMOOTH
CONTINUOUS
NON-DISTRACTING

Think of extremely subtle light moving through a dark room.

The gradient must never become bright enough to compete with text.

Use CSS animations or the existing animation library where appropriate.

Prefer GPU-friendly transforms/opacity.

Do not animate expensive blur effects continuously if avoidable.

==================================================
3. EDITORIAL GRID / TEXTURE
==================================================

If the existing design already contains grid lines, borders, or editorial guides:

make them subtly breathe/move.

For example:

- extremely slow horizontal/vertical drift
- tiny opacity variation
- subtle parallax relative to scroll

Keep this almost imperceptible.

DO NOT add a large obvious grid.

The current minimal editorial lines are part of the design language.

==================================================
4. SCROLL PARALLAX
==================================================

Add very subtle scroll-linked movement to selected visual elements.

Examples:

Hero background:
5–15px movement

Large editorial headings:
3–8px movement

Ambient gradient:
10–25px movement

Recovery Wall:
very subtle depth/parallax

Contact background:
5–10px movement

IMPORTANT:

Do NOT move entire sections dramatically.

Do NOT create motion sickness.

Do NOT make text float independently too much.

The effect should create DEPTH, not chaos.

==================================================
5. SCROLL REVEALS SHOULD NOT FEEL ONE-TIME ONLY
==================================================

The current website becomes static after the initial reveal.

Improve this carefully.

Use IntersectionObserver / existing animation system so selected elements can animate again when they re-enter the viewport.

However:

DO NOT replay dramatic entrance animations continuously.

Use two levels:

FIRST ENTRY:
slightly stronger reveal

SUBSEQUENT ENTRIES:
very subtle opacity/translate movement

For example:

First appearance:
opacity 0 → 1
translateY 20px → 0

Later appearances:
opacity 0.85 → 1
translateY 6px → 0

This should make scrolling back through the website feel alive without becoming repetitive.

==================================================
6. SECTION HEADINGS
==================================================

Give major editorial headings subtle motion.

Examples:

"Recent Recoveries."
"Where we work."
"Contact"
etc.

Use tiny translateY / opacity / letter-spacing adjustments.

Do NOT animate every word individually unless an existing component already does so.

Avoid flashy text scrambling.

Keep the typography premium.

Keep the existing Recovery Wall animation exactly as the foundation.

DO NOT increase blur.

DO NOT make the mobile Recovery Wall larger.

The existing mobile card sizing and reduced blur must remain.

==================================================

==================================================
12. FOOTER MOTION
==================================================

The footer should remain calm.

==================================================
13. PERFORMANCE
==================================================

This is extremely important.

Prefer:

transform
opacity
CSS gradients
requestAnimationFrame where actually needed
IntersectionObserver

Avoid:

continuous layout-triggering animations
heavy DOM particle systems
large canvas effects
massive box-shadow animations
constant expensive filter/blur calculations

The website must remain smooth on normal phones.

==================================================
14. MOBILE
==================================================

Keep:

ambient background movement
subtle scroll reveals
small parallax
button/link micro-interactions

Disable:

cursor effects
heavy parallax
large transforms
expensive effects

The website must remain fast and full-width.

==================================================
15. REDUCED MOTION
==================================================

Respect:

prefers-reduced-motion: reduce

When enabled, significantly reduce or disable non-essential motion.

alive

intentional
