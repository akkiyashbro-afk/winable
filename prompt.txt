IMPORTANT MOBILE MENU ANIMATION FIX

The mobile menu is currently opening and closing almost instantly.

I do NOT want a simple conditional render where the menu suddenly appears/disappears.

Make the EXISTING mobile menu fully animated in BOTH directions:

OPEN:
MENU button tap
→ overlay/background smoothly enters
→ grid/background fades in
→ menu header reveals
→ navigation rows animate in sequentially
→ bottom CTA reveals last

CLOSE:
Close/X or MENU button tap
→ CTA smoothly exits
→ navigation rows smoothly exit
→ header smoothly exits
→ background/grid fades away
→ overlay completely disappears

The entire transition must feel intentional, premium and fluid.
